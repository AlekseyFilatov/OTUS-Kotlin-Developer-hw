ModelEntity
 - id - уникалный идентификатор записи 
 - title - название
 - model - модель
 - created_at - дата создания
 - last_trained_at - дата тренировки
 - task_id - номер задания
 - parameters - параметры задания тренировки модели

ModelEntity - готовая модель хранящаяся в Postgres 

Данные для создания конкретной модели могут быть различными

Функции (эндпониты):
Название модели - запуск расчета

Сервис:
CRUDS (create, read, update, delete, search) для моделей
download для данных
models (опционально): возвращает список моделей, подходящих для выбранной модели
