Домашнее задание

Разработка слоя работы с базой данных в приложении

Цель:

• узнать об особенностях работы с БД в Kotlin;

• исследовать шаблон проектирования "репозиторий";

• научиться создавать InMemory репозиторий;

• разработать репозиторий на одной из баз данных: SQL (Postgres или другой), NoSQL (Cassandra), NewSQL (ArcadeDB);

• выполнить тестирование репозиториев;

• интегрировать репозитории в выпускное приложение.


Описание/Пошаговая инструкция выполнения домашнего задания:

• сделать интерфейс репозитария;

• сделать реализацию InMemoryDB репозитария;

• интегрировать репозитарий в выпускное приложение;

• выполнить интеграционное тестирование приложения с репозитарием;

• выбрать базу данных, которая будет использоваться в проекте;

• сделать реализацию репозитария для выбранной базы данных;

• сделать автотесты для репозитария.
