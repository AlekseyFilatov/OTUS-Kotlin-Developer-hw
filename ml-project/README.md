Домашнее задание

Разработка приложения с использованием фреймворков и асинхронным транспортом

Цель:

• освоить работу с одним из Web-фреймворков: Spring Framework, KTOR;

• изучить асинхронные фреймворки и библиотеки: RabbitMQ, Kafka, WebSocket;

• научиться работать с шаблоном Dependency Injection;

• выполнить интеграцию транспортных моделей в выпускное приложение;

• обеспечить выполнение стабовых запросов приложением на фреймворке.


Описание/Пошаговая инструкция выполнения домашнего задания:

• выбрать REST-фреймворк и асинхронный транспорт;

• реализовать приложения с их использованием;

• подключить модуль транспортных моделей к полученным приложениям;

• сделать заглушки, отдающие фейковый результат на запрос;

• сделать автоматические тесты;

• выполнить деплой в Docker.
